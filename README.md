# Recipe House

A responsive React single-page application for browsing recipes. Users can search recipes by name or category and sort them by preparation time or name.

## Technologies
- React
- Vite
- JavaScript, CSS

## Pages
Home, Login, Register, About

## Setup and Run
1. Install Node.js
2. Run npm install
3. Run npm run dev
4. Open the local link shown in the terminal

## Deployed Site
https://recipe-house.onrender.com
